# curva-fetal

Site estático de uma página só (`Curvas de Crescimento Fetal.html`), sem build step. O GitHub Pages publica a partir da branch `main`.

## Fluxo de deploy

Depois de terminar e validar uma mudança numa branch de trabalho, faça merge direto na `main` e dê push — sem pedir confirmação a cada vez. O GitHub Pages atualiza automaticamente em ~1 minuto após o push na `main`. Esse é o comportamento padrão combinado com o usuário; não é necessário reconfirmar isso a cada sessão.
